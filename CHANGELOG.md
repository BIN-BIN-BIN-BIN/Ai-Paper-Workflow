# Changelog · 版本记录

## 2.0.0 — 2026-11-24

- Merged the separate English and Chinese skills into **one bilingual `SKILL.md`**; the assistant replies in the user's language. / 中英文两个版本合并为**一个双语 `SKILL.md`**，按用户提问的语言回答。
- Added a label table for localisation; new languages are added as one column. / 新增本地化术语表，增加语言只需加一列。
- Removed all references to other skills; the skill is self-contained. / 删除对其他 skill 的引用，skill 可独立使用。
- Moved the skill to `skills/ai-paper-workflow/` and added installers for Claude Code, OpenAI Codex, Hermes Agent and WorkBuddy. / skill 移至 `skills/ai-paper-workflow/`，新增 Claude Code、OpenAI Codex、Hermes Agent、WorkBuddy 安装脚本。
- Added standard `license` and `metadata` fields (Agent Skills specification). / 增加 Agent Skills 规范中的 `license` 与 `metadata` 字段。
